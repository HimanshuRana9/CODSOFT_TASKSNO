# CODSOFT Data Analytics Internship

Repository for the CodSoft Data Analytics Internship tasks.

## Tasks
1. Data Cleaning & Preprocessing
2. Exploratory Data Analysis
3. Data Visualization Dashboard
4. Customer Data Analysis
5. Web Data Extraction & Analysis

## Current implementation
Task 1 is the first implementation phase. It uses the UCI Online Retail II dataset and a reproducible Pandas cleaning pipeline.

## Setup
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

Then run:
```bash
python Task_1_Data_Cleaning/scripts/download_dataset.py
python Task_1_Data_Cleaning/scripts/clean_dataset.py
```
